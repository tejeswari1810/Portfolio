# Portfolio: Advanced CSS3 & Responsive Architecture

Responsive portfolio with a light/dark theme.

- **CSS Grid**: page layout (sidebar + content), projects grid, contact form
- **Flexbox**: header, navigation, tags, cards, buttons
- **Mobile-first media queries**: base styles for phones, `48em` tablet, `64em` desktop
- **CSS variables**: theme tokens for light and dark mode, with a toggle button

Open `index.html` in a browser to view it.
